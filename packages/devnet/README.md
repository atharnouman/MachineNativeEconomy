# @spendmarshal/devnet

Local chain helpers for tests and demos: start anvil (Prague hardfork, so EIP-7702 works), deploy the contracts, delegate an EOA to `AgentAccount`, mint test USDC, grant sessions, a mock Lightning node.

Needs Foundry on PATH. Dev keys only; never point this at a funded wallet.

Part of [SpendMarshal](https://github.com/atharnouman/MachineNativeEconomy), the open-source Agentic Payment Gateway: policy, settlement and evidence between AI agents and any payment rail. Apache-2.0. Alpha: APIs change between 0.0.x versions.
