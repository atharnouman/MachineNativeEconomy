## Design decisions
- **Structural pre-check at amount 0.** The agent's `maxAmount` is a ceiling, not a price; evaluating budgets at the ceiling produced spurious denials (second escalation in the demo). Amount checks now run once on the quoted price.
- **Lineage spend propagates up** rather than partitioning caps at grant time, so chain and gateway share pool semantics.
- **Any active session key may pause; only the owner unpauses.** The admin kill-switch "off" therefore clears the gateway flag and reports `owner-required` when the gateway is not the owner.
- **Impact analysis uses an empty ledger** so it reports rule/caveat changes, not budget exhaustion.
- **Approver signatures** are EIP-191 over a canonical text binding id, principal, intentHash, amount, verdict.
- viem 2.57.3: `walletClient.signAuthorization({ contractAddress, executor: "self" })` + `sendTransaction({ authorizationList, to: self, data: initialize(owner) })`; anvil needs `--hardfork prague`; forge needs `evm_version = "prague"` for `vm.signAndAttachDelegation`.

## 11 Oct 2026: live Base Sepolia run, what broke and what was fixed
- Public RPC (sepolia.base.org) is load-balanced: balances, `getCode` after the 7702 delegation and a fresh session were all stale for a few seconds after the receipt. Fixes: polling in the runner after every transaction, `delegateEoaToAccount` polls `getCode`, `register()` polls `readSession` and the bounded-operator check retries.
- The runner generated a new payee treasury per run while the root session's target allowlist named the first one → `ChildExceedsParent`. The treasury now lives in `local/testnet-deploy.json` next to the contracts.
- A credential with `expires_at` 24 h later than the gateway's root session → `ChildExceedsParent(validUntil)`. The gateway now clamps a child session's caps and window to the parent's (on-chain is the backstop; the credential's own caveats stay enforced off-chain).
- The payee appended `/facilitator/verify` to `facilitatorUrl`, which only matched the bundled facilitator; the x402 convention is base + `/verify|/settle|/supported`. Demos now pass `${gatewayUrl}/facilitator`; the public URL is used as-is; facilitator errors become 402 with the reason instead of a 500.
- Faucets: Circle (USDC, reCAPTCHA on the click, the user clicks), Coinbase Developer Platform (0.0001 ETH per claim, needs the user's sign-in; Google sign-in popups are blocked in the built-in browser pane, so the user used Chrome). Gas at 0.006 gwei makes 0.0001 ETH enough for the whole run; the runner moves a quarter to the owner.
